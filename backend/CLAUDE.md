# Hotbox — Backend (`backend/`)

The Convex backend shared by the admin dashboard and the mobile app. Shared repo rules (git workflow, guardrails) live in the root [CLAUDE.md](../CLAUDE.md).

- **Backend:** Convex (`convex/` — schema, queries, mutations, actions)
- **Auth:** Clerk, configured in `convex/auth.config.ts`. The admin app wires the client in `admin/components/ConvexClientProvider.tsx`.

## Commands

Run from inside `backend/`. `dev` is a long-running process — run it in its own terminal, separate from the admin Next server.

- **Install:** `pnpm install`
- **Dev (Convex):** `pnpm dev`
- **Lint:** `pnpm lint`
- **Typecheck:** `pnpm typecheck`

Use `pnpm exec convex <command>` (not `npx`) for other Convex CLI commands.

`convex/_generated/` is generated by `pnpm dev`; never edit it by hand.
